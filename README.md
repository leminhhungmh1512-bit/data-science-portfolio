# Data Science Portfolio — Minh Hung Le

I am a Bachelor of Science student majoring in Data Science at The University of Western Australia, based in Perth. This portfolio presents selected work in statistical modelling, data analysis, simulation and algorithm design.

I am interested in data analytics and business intelligence, particularly preparing reliable data and explaining results clearly for reporting and decision-making.

## Projects

| Project | Focus | Tools |
| --- | --- | --- |
| [Australia and New Zealand Census Analysis](https://github.com/leminhhungmh1512-bit/data-science-portfolio/tree/main/census-analysis-australia-new-zealand) | Migration patterns, cultural diversity, data preparation and visual comparison using national Census data | Python, pandas, NumPy, Matplotlib, Jupyter |
| [Perth Climate Analysis](https://github.com/leminhhungmh1512-bit/data-science-portfolio/tree/main/perth-climate-analysis) | Relationship between solar exposure and temperature anomalies, plus statistical power simulation | R, regression, hypothesis testing, simulation |
| [Environmental and Mortality Modelling](https://github.com/leminhhungmh1512-bit/data-science-portfolio/tree/main/environmental-mortality-modelling) | Exploratory analysis, model selection, regression diagnostics and causal inference | R, statistical modelling, simulation |
| [Organisation Analytics](https://github.com/leminhhungmh1512-bit/data-science-portfolio/tree/main/organisation-analytics-python) | Data validation, statistical comparison, distance measurement and category ranking | Python, CSV processing, descriptive statistics |
| [Network Routing and Connectivity](https://github.com/leminhhungmh1512-bit/data-science-portfolio/tree/main/network-routing-algorithms) | Security-constrained shortest paths and time-dependent rail connectivity | Python, Dijkstra, custom min-heap, Union-Find |

## Technical Skills Demonstrated

- **Programming and query languages:** Python, R and SQL
- **Analysis:** exploratory data analysis, hypothesis testing, regression, simulation, model diagnostics, model selection and causal inference
- **Tools and libraries:** GitHub, Jupyter Notebook, Microsoft Excel, pandas, NumPy and Matplotlib
- **Computer science foundations:** relational databases, data structures, graph algorithms and complexity analysis

I am currently learning Power BI, with DAX, Power Query and Power Automate as areas to develop. These tools are not used in the projects listed here.
