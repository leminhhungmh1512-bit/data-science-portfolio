# Data Science Portfolio — Minh Hung Le

I am a Bachelor of Science student majoring in Data Science at The University of Western Australia, based in Perth. This portfolio presents selected work in statistical modelling, data analysis, simulation and algorithm design.

I am interested in using data and technology to solve practical operational problems, particularly in infrastructure, energy and sustainability.

## Projects

| Project | Focus | Tools |
| --- | --- | --- |
| [Perth Climate Analysis](./perth-climate-analysis) | Relationship between solar exposure and temperature anomalies, plus statistical power simulation | R, regression, hypothesis testing, simulation |
| [Environmental and Mortality Modelling](./environmental-mortality-modelling) | Exploratory analysis, model selection, regression diagnostics and causal inference | R, statistical modelling, simulation |
| [Organisation Analytics](./organisation-analytics-python) | Data validation, statistical comparison, distance measurement and category ranking | Python, CSV processing, descriptive statistics |
| [Network Routing and Connectivity](./network-routing-algorithms) | Security-constrained shortest paths and time-dependent rail connectivity | Python, Dijkstra, custom min-heap, Union-Find |

## Technical Skills Demonstrated

- **Programming and query languages:** Python, R and SQL
- **Analysis:** exploratory data analysis, hypothesis testing, regression, simulation, model diagnostics, model selection and causal inference
- **Tools and libraries:** GitHub, Microsoft Power BI, Microsoft Excel, Pandas, NumPy and Matplotlib
- **Computer science foundations:** relational databases, data structures, graph algorithms and complexity analysis
